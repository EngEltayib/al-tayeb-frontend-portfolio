## Overview

Production SaaS dashboard work at AlexApps across service management, offers, restaurants, vendors, clients, and account workflows with multi-role access and API-driven data.

## The goal

Build maintainable interfaces for data-heavy, multi-role business workflows while keeping permissions, backend state, and bilingual UI behavior consistent.

## My role

Frontend Developer working across dashboard modules and end-to-end business features.

## What I implemented

- REST API integration across production dashboard modules.
- OTP authentication, protected routes, RBAC, and permission-aware navigation.
- Server-side filtering, pagination, and debounced search.
- Approval and status-driven workflows.
- Arabic and English support with RTL/LTR behavior.
- Multi-step onboarding and registration flows.
- Tap Payments integration in applicable product flows.

## Main challenge

Keeping permissions, backend-driven states, forms, navigation, and multilingual behavior consistent across multiple roles and modules.

## Approach

I used reusable patterns for authorization-aware UI, form validation, API integration, shared state, and server-driven filtering and pagination while coordinating closely with backend requirements.

## Technologies

React.js, Next.js, TypeScript, Material UI, React Hook Form, Yup, Axios, REST APIs, next-intl, and Git.

## Outcome

Delivered production features across multiple SaaS workflows. No public performance or revenue metrics are claimed without verification.

## نظرة عامة

عمل إنتاجي في AlexApps على لوحات تحكم SaaS تشمل إدارة الخدمات والعروض والمطاعم والموردين والعملاء والحسابات، مع صلاحيات متعددة وبيانات تعتمد على APIs.

## الهدف

بناء واجهات قابلة للصيانة لتدفقات أعمال كثيفة البيانات ومتعددة الأدوار، مع الحفاظ على اتساق الصلاحيات وحالات Backend وسلوك الواجهة ثنائية اللغة.

## دوري

مطور واجهات أمامية أعمل على وحدات لوحة التحكم وخصائص المنتج من البداية إلى النهاية.

## ما نفذته

- ربط REST APIs عبر وحدات إنتاجية متعددة.
- مصادقة OTP ومسارات محمية وRBAC وتنقل يعتمد على الصلاحيات.
- تصفية من جهة الخادم وتقسيم صفحات وبحث مؤجل.
- تدفقات الموافقة والواجهات المبنية على الحالات.
- دعم العربية والإنجليزية مع RTL/LTR.
- تدفقات تسجيل وتهيئة مستخدم متعددة الخطوات.
- ربط Tap Payments داخل تدفقات المنتج المناسبة.

## التحدي الرئيسي

الحفاظ على اتساق الصلاحيات والحالات القادمة من Backend والنماذج والتنقل واللغتين عبر أدوار ووحدات متعددة.

## طريقة التعامل

استخدمت أنماطًا قابلة لإعادة الاستخدام للواجهات المدركة للصلاحيات والتحقق من النماذج وربط APIs والحالة المشتركة والتصفية وتقسيم الصفحات من جهة الخادم، مع التنسيق المستمر مع متطلبات Backend.

## التقنيات

React.js، Next.js، TypeScript، Material UI، React Hook Form، Yup، Axios، REST APIs، next-intl، وGit.

## النتيجة

تسليم خصائص إنتاجية عبر عدة تدفقات SaaS، بدون ادعاء مؤشرات أداء أو إيرادات غير موثقة.
